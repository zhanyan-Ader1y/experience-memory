# 压缩留存补充协议 v1

核心规则固定保留，不参与非核心淘汰。非核心只保留已核验、已有效使用登记的条目，标记与一行摘要整条保留或整条淘汰，不改写标记、等级、ID 或 U。

超预算先淘汰 P3，再 P2，再 P1；同等级先淘汰 U 最小的旧内容，同等级同 U 按经验 ID 的 ASCII 字典升序淘汰。同 ID 只留最新有效版本。

总预算按本扩展完整 additionalContext 的 UTF-8 字节计算，包含通用协议、项目核心和包装。核心自身超预算时明确失败，不淘汰核心。压缩/恢复不刷新 U。

正式留存区以运行时选取并确认的集合为准，不能由旧摘要重建。该资源供后续受支持的压缩入口使用；当前 PreCompact 不追加它，也不覆盖宿主 compact_prompt。
