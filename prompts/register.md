# 有效使用登记协议 v1

使用当前会话已核验的精确读取回执；只有经验实际支持判断、动作或校验，才提交 `memory_use`，并说明用途。压缩、恢复、纯召回和重复显示不分配新 U。

标记结构：`【留存:P等级|经验ID|U序号】一行摘要`。P1 为当前任务必要约束，P2 为适用经验，P3 为参考；P1 高于 P2，高于 P3。U 是服务端提交并回读确认的本会话有效使用序号，agent 不自行生成或刷新。

同经验 ID 只采用最新有效版本，版本/摘要指纹与读取回执绑定。相同操作重试复用操作标识，不产生第二次逻辑效果。结果未知先定案，再提交后续操作。

应用内核与 Mem0 仓储已实现；实际宿主会话来源、压缩边界及注入效果仍待 G1 验收。
